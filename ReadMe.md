# Secure and Intelligent Home Health Monitoring System using IoT and Machine Learning

## Project Overview
This project focuses on developing a smart home-based health monitoring system for cardiovascular disease patients. It is designed to support remote patient monitoring, especially in resource-constrained environments.

## Problem Statement
Many patients with heart conditions lack continuous monitoring due to limited access to healthcare facilities. This can delay medical intervention and increase health risks.

## Solution
The system allows patients to measure vital signs such as:
- Body Temperature
- Heart Rate
- Oxygen Saturation (SpO₂)

The data is transmitted to a cloud-based platform where healthcare professionals can monitor patients in real time.

## Key Features
- IoT-based sensor integration
- Real-time data monitoring
- SMS alerts for low connectivity areas
- MQTT protocol for secure data transmission
- Machine Learning for anomaly detection
